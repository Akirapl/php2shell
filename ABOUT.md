# About / O projekcie / Über

## Polski

To niezależny, niekomercyjny projekt o charakterze obronnym i dziennikarskim. Prowadzi go użytkownik GitHub [@Akirapl](https://github.com/Akirapl).

Materiał przygotowano z pomocą AI. Każdy fakt jest sprawdzany wobec cytowanego źródła i oznaczany poziomem pewności: `confirmed` (potwierdzone), `reported` (relacjonowane) albo `estimate` (szacunek).

Projekt nie jest powiązany z projektem PHP, z Wiz, z Calif ani z żadnym dostawcą.

Z założenia nie ma tu kodu exploita ani instrukcji ataku.

Korekty, nowe źródła i poprawki tłumaczeń: [GitHub Issues](https://github.com/Akirapl/php2shell/issues/new/choose) ([CONTRIBUTING.md](CONTRIBUTING.md)). Zasady dotyczące treści wrażliwych: [SECURITY.md](SECURITY.md). Plan archiwum: [ARCHIVE.md](ARCHIVE.md). Centrum na żywo: <https://akirapl.github.io/php2shell/> (stary adres php2shell-live.surge.sh tylko przekierowuje).
