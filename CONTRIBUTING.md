# Contributing / Zgłoszenia / Beiträge

Zgłoszenia idą przez GitHub Issues: <https://github.com/Akirapl/php2shell/issues/new/choose>

Reports go through GitHub Issues: <https://github.com/Akirapl/php2shell/issues/new/choose>

Meldungen laufen über GitHub Issues: <https://github.com/Akirapl/php2shell/issues/new/choose>

Puste zgłoszenia są wyłączone. Szablony: korekta, nowe źródło, poprawka tłumaczenia.

Blank issues are disabled. Templates: correction, new source, translation fix.

Leere Issues sind deaktiviert. Vorlagen: Korrektur, neue Quelle, Übersetzungsfehler.

Live center / Centrum na żywo / Live-Center: <https://akirapl.github.io/php2shell/>

## Polski

### Korekta

Szablon „Correction / Korekta / Korrektur”. W zgłoszeniu:

- zacytuj błędne zdanie,
- wskaż miejsce: plik i sekcja albo identyfikator pozycji w centrum na żywo,
- podaj link do źródła (pole wymagane),
- podaj język.

### Nowe źródło

Szablon „New source / Nowe źródło / Neue Quelle”: adres URL, co źródło dodaje, data publikacji.

### Poprawka tłumaczenia

Szablon „Translation / Tłumaczenie / Übersetzung”: język, miejsce, obecne brzmienie i propozycja.

Przyjęta korekta trafia do [CHANGELOG.md](CHANGELOG.md). Zmianę widać w historii commitów: <https://github.com/Akirapl/php2shell/commits/main>.

Szczegółów exploita i instrukcji ataku nie wklejaj. Patrz [SECURITY.md](SECURITY.md).

## English

### Correction

Use the template “Correction / Korekta / Korrektur”. In the report:

- quote the wrong statement,
- say where it is: file and section, or the live-center item id,
- give a source link (required),
- give the language.

### New source

Use “New source / Nowe źródło / Neue Quelle”: the URL, what it adds, and the publication date.

### Translation fix

Use “Translation / Tłumaczenie / Übersetzung”: language, location, the current wording, and the suggested wording.

An accepted correction is logged in [CHANGELOG.md](CHANGELOG.md). The change is visible in the commit history: <https://github.com/Akirapl/php2shell/commits/main>.

Do not paste exploit details or attack instructions. See [SECURITY.md](SECURITY.md).

## Deutsch

### Korrektur

Vorlage „Correction / Korekta / Korrektur“. In der Meldung:

- die falsche Aussage zitieren,
- den Ort nennen: Datei und Abschnitt oder die Kennung im Live-Center,
- einen Quellenlink angeben (Pflichtfeld),
- die Sprache angeben.

### Neue Quelle

Vorlage „New source / Nowe źródło / Neue Quelle“: URL, was die Quelle ergänzt, Veröffentlichungsdatum.

### Übersetzungsfehler

Vorlage „Translation / Tłumaczenie / Übersetzung“: Sprache, Ort, bisherige Formulierung und Vorschlag.

Eine angenommene Korrektur wird in [CHANGELOG.md](CHANGELOG.md) eingetragen. Die Änderung steht in der Commit-Historie: <https://github.com/Akirapl/php2shell/commits/main>.

Keine Exploit-Details und keine Angriffsanleitungen einfügen. Siehe [SECURITY.md](SECURITY.md).
