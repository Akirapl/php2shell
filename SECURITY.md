# Security / Bezpieczeństwo / Sicherheit

## Polski

To repozytorium nie przyjmuje i nie publikuje szczegółów podatności ani exploitów. Szczegółów exploita nie zamieszczaj w Issues.

Podatności w samym PHP zgłaszaj oficjalnym kanałem projektu PHP:

- formularz: <https://github.com/php/php-src/security/advisories/new>
- gdy formularz jest niedostępny albo sprawa nie jest zwykłym zgłoszeniem błędu: [security@php.net](mailto:security@php.net)

Oba kontakty podaje [`SECURITY.md` w php/php-src](https://github.com/php/php-src/blob/master/SECURITY.md) oraz plik <https://www.php.net/.well-known/security.txt> (wiersze `Contact`, data wygaśnięcia `Expires: 2026-11-28T11:59:59.999Z`).

Centrum na żywo: <https://akirapl.github.io/php2shell/>. Wbudowana sprawdzarka banera jest pasywna; sprawdzaj nią tylko własne systemy lub takie, na których test masz zgodę.

Uwagi do treści tego repozytorium, na przykład fragment zbyt szczegółowy: prywatne zgłoszenia podatności na GitHubie są tu wyłączone (sprawdzone 21.10.2026 przez API repozytorium, `enabled: false`). Otwórz [Issue](https://github.com/Akirapl/php2shell/issues/new/choose) i pomiń wrażliwy szczegół. Gdy właściciel włączy prywatne zgłoszenia, użyj <https://github.com/Akirapl/php2shell/security/advisories/new>.

## English

This repository does not accept or publish vulnerability details or exploits. Never post exploit details in issues.

Vulnerabilities in PHP itself go to the PHP project’s official security reporting channel:

- form: <https://github.com/php/php-src/security/advisories/new>
- if the form cannot be used, or the matter is not an ordinary bug report: [security@php.net](mailto:security@php.net)

Both contacts are stated in [`SECURITY.md` in php/php-src](https://github.com/php/php-src/blob/master/SECURITY.md) and in <https://www.php.net/.well-known/security.txt> (`Contact` lines; `Expires: 2026-11-28T11:59:59.999Z`).

Live center: <https://akirapl.github.io/php2shell/>. Its built-in banner checker is passive; use it only on systems you own or are authorised to test.

Concerns about this repository’s own content, for example a passage that is too detailed: GitHub private vulnerability reporting is disabled here (checked on 21.10.2026 via the repository API, `enabled: false`). Open an [issue](https://github.com/Akirapl/php2shell/issues/new/choose) and leave out the sensitive detail. If the owner enables private reporting later, use <https://github.com/Akirapl/php2shell/security/advisories/new>.

## Deutsch

Dieses Repository nimmt keine Details zu Schwachstellen und keine Exploits an und veröffentlicht sie nicht. Exploit-Details gehören nicht in Issues.

Schwachstellen in PHP selbst gehen an den offiziellen Meldeweg des PHP-Projekts:

- Formular: <https://github.com/php/php-src/security/advisories/new>
- wenn das Formular nicht nutzbar ist oder es kein gewöhnlicher Fehlerbericht ist: [security@php.net](mailto:security@php.net)

Beide Kontakte stehen in [`SECURITY.md` in php/php-src](https://github.com/php/php-src/blob/master/SECURITY.md) und in <https://www.php.net/.well-known/security.txt> (Zeilen `Contact`; `Expires: 2026-11-28T11:59:59.999Z`).

Live-Center: <https://akirapl.github.io/php2shell/>. Der eingebaute Banner-Checker ist passiv; prüfen Sie damit nur eigene Systeme oder solche, für deren Test Sie eine Erlaubnis haben.

Hinweise zum Inhalt dieses Repositories, zum Beispiel eine zu detaillierte Stelle: Die private Schwachstellenmeldung auf GitHub ist hier deaktiviert (geprüft am 21.10.2026 über die Repository-API, `enabled: false`). Öffne ein [Issue](https://github.com/Akirapl/php2shell/issues/new/choose) und lass das sensible Detail weg. Wenn der Eigentümer die private Meldung später einschaltet, gilt <https://github.com/Akirapl/php2shell/security/advisories/new>.
